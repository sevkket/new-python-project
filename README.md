# Haber Merkezi 📰

Modern ve kullanıcı etkileşimli bir haber paylaşım platformu.

## Özellikler

- Güncel haberleri listeleme
- Kategoriye göre haber filtreleme
- Haber arama sistemi
- Haber detay sayfası
- Kullanıcı kayıt / giriş sistemi
- Haber beğeni & dislike sistemi
- Favorilere ekleme sistemi
- Yorum sistemi
- Admin paneli
- Karanlık / aydınlık tema
- Görsel bulunamazsa otomatik placeholder sistemi
- RSS + NewsAPI destekli haber çekme sistemi

---

## Kullanılan Teknolojiler

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

---

## Kurulum

### 1. Projeyi indir
2. Proje klasörünü VS Code ile açın.
3. Terminali açın.
4. Gerekli paketleri yüklemek için `pip install -r requirements.txt` komutunu çalıştırın.
5. Uygulamayı başlatmak için `py app.py` komutunu çalıştırın.
6. Tarayıcıdan `http://127.0.0.1:5000` adresine girin.
